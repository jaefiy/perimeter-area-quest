# Perimeter and Area Quest

A static educational game website designed for Year 5 Malaysian primary students.

## Curriculum Alignment
Aligned with **Year 5 KSSR Mathematics 6.3.1 perimeter of composite shapes and 6.3.2 area of composite shapes of two shapes**.

## How to Run Tests
To execute the test suite for core mathematical calculations:
```bash
node tests/mathcore.test.js
```
